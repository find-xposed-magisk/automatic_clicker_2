# packaging 打包目录说明

本目录集中存放本项目的 PyInstaller spec 和打包说明。所有命令都应在项目根目录执行。

## 推荐命令

```text
pyinstaller --clean -y packaging\main.spec
```

`packaging\main.spec` 使用便携式 onedir 结构，`data` 位于 `Clicker.exe` 同级目录。升级程序时必须保留用户现有的 `data` 文件夹。

## Nuitka

如使用 Nuitka，只支持能在可执行文件同级保留外部 `data` 的 standalone 发布方式：

```text
nuitka --standalone --enable-plugin=pyside6 --plugin-enable=tk-inter --windows-icon-from-ico=clicker.ico --include-data-dir=flat=flat --include-data-dir=data=data --include-package=pygments --include-package=pyttsx4 --include-package=webdriver_manager --include-package-data=selenium --remove-output main.py
```

不要直接使用 onefile 打包内嵌 `data`，临时解压目录中的配置和数据库无法作为持久化数据使用。

## 目录约束

- 不要进入 `packaging` 后执行命令，spec 中的路径统一从项目根目录解析。
- `build`、`dist` 是构建输出目录，继续位于项目根目录，不放入 `packaging`。
- `clicker.ico` 是应用图标，按参考项目结构保留在项目根目录。
